Загрузить отчёт из файла

CSV-выгрузки из кабинетов ВБ и Ozon; ошибки чисел, дат и кодировок исправляются автоматически. Можно загрузить несколько файлов — они дополняют друг друга.

Выбор здесь привязывает данные к маркетплейсу (это нужно для сравнения ВБ и Ozon). Файл ВБ грузите с «Wildberries», файл Ozon — переключив на «Ozon». Если в самом файле есть колонка «Маркетплейс», она имеет приоритет для каждой строки.

Себестоимость товаров

CSV со столбцами SKU и себестоимостью за штуку — включит расчёт чистой прибыли. Можно грузить несколько файлов (например, отдельно ВБ и Ozon) — они дополняют друг друга.

Понимает «Полная себестоимость за шт», «Себестоимость закупки за шт» или просто «Себестоимость». Несколько файлов складываются; если один SKU встретится дважды, берётся последнее значение. Пока файл не загружен, анализ идёт без неё — по метрике «к выплате».
