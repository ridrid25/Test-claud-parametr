# Ролик воронки №1 — «Сколько вы ЗАРАБОТАЛИ на самом деле?»

**Хронометраж:** 20–25 с, вертикаль 1080x1920, титры в стиле проекта
(Montserrat ExtraBold, белый с чёрной обводкой). Стиль — как чек-лист v9:
фейл-хук → быстрый показ → пейофф. Без лиц: экран с цифрами + курсор.

| Время | Кадр | Титр | Голос/суть |
|---|---|---|---|
| 0–2 с | Скрин отчёта WB: простыня из сотен строк, быстрый скролл | «отчёт WB выглядит ТАК 🤯» | Хук-фрустрация: узнаваемая боль |
| 2–5 с | Стоп-кадр, курсор тычет в «К перечислению» | «эта цифра — НЕ ваша прибыль» | Ошибка, которую делают все |
| 5–11 с | Каскад из дашборда: строки появляются по одной — комиссия, логистика, штрафы, удержания (красные), компенсации (зелёная) | «минус комиссия → логистика → штрафы…» | Показ метода: 4 быстрых удара |
| 11–14 с | Строка «РАСХОЖДЕНИЕ: 0,00 ₽» — зум-панч + дзынь | «сошлось ДО РУБЛЯ ✅» | Момент-пейофф (наш «flash») |
| 14–19 с | Строка «ПРИБЫЛЬ ПЕРИОДА» крупно, рядом маржа | «вот сколько вы заработали НА САМОМ ДЕЛЕ» | Результат |
| 19–25 с | Экран сервиса mp.ridfinance.ru | «загрузите свой отчёт — бесплатно» | CTA: сервис, не персона |

**Правила:** сервис, а не человек — без имён и регалий; глагол CTA —
«загрузите, посмотрите сами». Музыку кладём в Instagram.
**Производство:** записать экран с дашбордом (телефон или OBS), прислать мне —
соберу по конвейеру v9 (зумы, дзынь на «0,00 ₽», титры) за один проход.
