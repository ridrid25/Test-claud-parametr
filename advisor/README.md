# Сервер-советник (merchant-agent для дашборда «Финсрез / МП»)

Вкладка «Советник» в дашборде отправляет сюда агрегаты (нормализованные строки
отчёта, себестоимость, остатки, рекламу, режим налога) и получает ответ торгового
агента из [anthropics/commerce-agents](https://github.com/anthropics/commerce-agents).
Сервер ничего не хранит; ключ Anthropic лежит только на нём.

## Установка (один раз)

Нужен Python 3.11+ и git.

**Windows (PowerShell):**
```powershell
cd путь\к\Test-claud-parametr
.\advisor\install.ps1
```

**macOS / Linux:**
```bash
cd путь/к/Test-claud-parametr
bash advisor/install.sh
```

Скрипт клонирует commerce-agents в соседнюю папку `../commerce-agents`, создаёт
виртуальное окружение и ставит зависимости.

## Запуск

**Windows (PowerShell):**
```powershell
$env:PILOT_ANTHROPIC_KEY = "sk-ant-..."      # ключ только в памяти этого окна
.\advisor\start.ps1
```

**macOS / Linux:**
```bash
export PILOT_ANTHROPIC_KEY=sk-ant-...
bash advisor/start.sh
```

В окне появится строка `Советник: http://127.0.0.1:8010  ключ: есть`. Окно не
закрывайте, пока пользуетесь советником. Дальше в дашборде: вкладка «Советник» →
«Проверить связь» → любая кнопка вопроса.

Без ключа сервер тоже запускается, но отвечает «сухим прогоном»: инструменты
работают, текста модели нет. Это удобно для проверки связи.

## Что уходит и куда

- Из браузера на сервер: строки отчёта в схеме дашборда (дата, артикул, суммы),
  себестоимость и остатки по SKU, строки рекламных выгрузок, период фильтра,
  режим налога. Исходные файлы кабинетов не отправляются.
- С сервера в API Anthropic: то, что модель запрашивает инструментами (сводка,
  алерты, кампании, серии метрик) и контекст магазина с итогами. Это
  единственное место, где данные покидают ваш компьютер.
- Сервер не пишет на диск и не ведёт журнал с данными.

## Проверка без дашборда

```bash
curl http://127.0.0.1:8010/health
```

## Настройки

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `PILOT_ANTHROPIC_KEY` или `ANTHROPIC_API_KEY` | ключ Anthropic | нет → сухой прогон |
| `COMMERCE_AGENTS_DIR` | путь к клону commerce-agents | `../commerce-agents` |
| `ADVISOR_PORT` | порт | 8010 |
| `ADVISOR_HOST` | адрес | 127.0.0.1 (только этот компьютер) |
