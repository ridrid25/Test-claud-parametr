# Сервер-советник (merchant-agent для дашборда «Финсрез / МП»)

Вкладка «Советник» в дашборде отправляет сюда агрегаты (нормализованные строки
отчёта, себестоимость, остатки, рекламу, режим налога) и получает ответ торгового
агента из [anthropics/commerce-agents](https://github.com/anthropics/commerce-agents).
Сервер ничего не хранит; ключ Anthropic лежит только на нём.

## Установка (один раз)

Нужен Python 3.11+ и git.

**Windows (PowerShell):**
```powershell
cd путь\к\Test-claud-parametr
.\advisor\install.ps1
```

**macOS / Linux:**
```bash
cd путь/к/Test-claud-parametr
bash advisor/install.sh
```

Скрипт клонирует commerce-agents в соседнюю папку `../commerce-agents`, создаёт
виртуальное окружение и ставит зависимости.

## Запуск

**Windows (PowerShell):**
```powershell
$env:PILOT_ANTHROPIC_KEY = "sk-ant-..."      # ключ только в памяти этого окна
.\advisor\start.ps1
```

**macOS / Linux:**
```bash
export PILOT_ANTHROPIC_KEY=sk-ant-...
bash advisor/start.sh
```

В окне появится строка `Советник: http://127.0.0.1:8010  ключ: есть`. Окно не
закрывайте, пока пользуетесь советником. Дальше в дашборде: вкладка «Советник» →
«Проверить связь» → любая кнопка вопроса.

Без ключа сервер тоже запускается, но отвечает «сухим прогоном»: инструменты
работают, текста модели нет. Это удобно для проверки связи.

## Что уходит и куда

- Из браузера на сервер: строки отчёта в схеме дашборда (дата, артикул, суммы),
  себестоимость и остатки по SKU, строки рекламных выгрузок, период фильтра,
  режим налога. Исходные файлы кабинетов не отправляются.
- С сервера в API Anthropic: то, что модель запрашивает инструментами (сводка,
  алерты, кампании, серии метрик) и контекст магазина с итогами. Это
  единственное место, где данные покидают ваш компьютер.
- Сервер не пишет на диск и не ведёт журнал с данными.

## Если сайт «не видит» сервер

Сайт открыт по HTTPS (github.io), сервер — локальный. Chrome требует от сервера
согласия на такие обращения (Private Network Access); сервер версии 1.1 отвечает
нужным заголовком. Если «Проверить связь» пишет «недоступен», а `/health` в
адресной строке браузера открывается: обновите репозиторий (`git pull`) и
перезапустите сервер. Встроенные браузеры некоторых приложений (например,
агентов-помощников) такие обращения блокируют всегда — проверяйте в обычном
Chrome, Edge или Яндекс Браузере.

## Рекламные кабинеты по API (без файлов)

Кнопка «Подтянуть из кабинетов» на вкладке «Загрузка» → «Рекламный кабинет»
просит сервер забрать статистику кампаний за период фильтра дат. Ключи кабинетов
живут только в окружении сервера и уходят только в API самих маркетплейсов;
сервер их не показывает, не пишет на диск и ничего в кабинетах не меняет
(только чтение: список кампаний и статистика).

Где взять ключи и куда положить:

| Переменная | Где взять | Зачем |
|---|---|---|
| `WB_API_TOKEN` | Кабинет WB → Настройки → Доступ к API → Создать токен. Категории: **«Продвижение»** (обязательно) и **«Контент»** (желательно). Тип токена — «только на чтение». Строка вида `eyJhbGci…` | статистика кампаний по дням и артикулам (nmId). «Контент» нужен, чтобы заменить nmId на ваш артикул продавца |
| `OZON_PERF_CLIENT_ID`, `OZON_PERF_CLIENT_SECRET` | performance.ozon.ru → Настройки → API-ключи → Создать. Client ID вида `12345678-1234567890@advertising.performance.ozon.ru`, секрет — длинная строка. Это **не** ключ Seller API | список кампаний и отчёт по кампаниям (SKU, показы, клики, расход, заказы) |
| `OZON_CLIENT_ID`, `OZON_API_KEY` | seller.ozon.ru → Настройки → API-ключи (Seller API), необязательно | заменить числовой SKU Ozon на ваш артикул. Без них дашборд сопоставляет по названию товара |

**Windows** (один раз, для пользователя; окно PowerShell после этого закрыть и
открыть заново; ярлык «Советник.cmd» перезапустить):
```powershell
[Environment]::SetEnvironmentVariable("WB_API_TOKEN", "eyJ…", "User")
[Environment]::SetEnvironmentVariable("OZON_PERF_CLIENT_ID", "…@advertising.performance.ozon.ru", "User")
[Environment]::SetEnvironmentVariable("OZON_PERF_CLIENT_SECRET", "…", "User")
```

**macOS / Linux** — те же имена через `export` перед `bash advisor/start.sh`.

Проверка: «Советник» → «Проверить связь» покажет «Ключи кабинетов: WB есть,
Ozon есть». Затем «Загрузка» → «Подтянуть из кабинетов». WB отдаёт статистику не
чаще одного запроса в минуту (каждые 100 кампаний × 31 день — минута), Ozon
строит отчёт до минуты; за месяц с десятком кампаний ждать 10–60 секунд.

Без дашборда — из командной строки, с сохранением CSV, который потом можно
загрузить кнопкой «Загрузить рекламу» на любом компьютере:
```powershell
python -m advisor.cabinets --from 2026-07-27 --to 2026-08-23 --csv реклама.csv
```

Сервер отдаёт строки в едином виде: кампания, тип, дата, артикул, номер в
кабинете, товар, показы, клики, затраты, заказы, сумма заказов. Ставки, бюджеты
и настройки кампаний не запрашиваются и не меняются.

## Проверка без дашборда

```bash
curl http://127.0.0.1:8010/health
```

## Настройки

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `PILOT_ANTHROPIC_KEY` или `ANTHROPIC_API_KEY` | ключ Anthropic | нет → сухой прогон |
| `COMMERCE_AGENTS_DIR` | путь к клону commerce-agents | `../commerce-agents` |
| `ADVISOR_PORT` | порт | 8010 |
| `ADVISOR_HOST` | адрес | 127.0.0.1 (только этот компьютер) |
| `WB_API_TOKEN` | токен WB с категориями «Продвижение» (+ «Контент») | нет → кнопка «Подтянуть из кабинетов» без WB |
| `OZON_PERF_CLIENT_ID`, `OZON_PERF_CLIENT_SECRET` | ключи Ozon Performance API | нет → без Ozon |
| `OZON_CLIENT_ID`, `OZON_API_KEY` | ключи Ozon Seller API (сопоставить SKU с артикулом) | нет → по названию товара |
| `WB_MIN_INTERVAL` | пауза между запросами статистики WB, с | 61 |
